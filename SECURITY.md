# Security Policy / Política de Seguridad

## Privacy & Local Processing Guarantee
Urraca PDF executes PDF editing, conversion, merging, splitting, OCR, redaction, signing, and batch operations **100% locally on the user's Windows device**. Documents are never uploaded to external servers.

## Installer Integrity Verification
Every official Windows release is digitally signed and published with a SHA-256 checksum on [urracapdf.com/download/](https://urracapdf.com/download/) and in the corresponding GitHub Release.

- **Current Release (`v1.7.1`, `Urraca_1.7.1_x64-setup.exe`):**

## Reporting a Vulnerability
If you discover a security or privacy issue in Urraca PDF or its installer/updater, **do not open a public issue**. Please report it privately to:

- **Email:** `support@urracapdf.com`
- Include steps to reproduce, Windows version, and Urraca PDF version.

We respond to security disclosures promptly and acknowledge researchers when fixes ship.
